DETAILED STEPS
═════════════════════════════════════════════════════════════════════════════════

STEP 1: ENVIRONMENT SETUP
─────────────────────────────────────────────────────────────────────────────────

If you don't have a virtual environment yet:
    python -m venv .venv

Activate it:
    Windows:  .venv\Scripts\activate
    Mac:      source .venv/bin/activate
    Linux:    source .venv/bin/activate

You should see (.venv) at the start of your terminal line.


STEP 2: INSTALL DEPENDENCIES
─────────────────────────────────────────────────────────────────────────────────

Install all required packages:
    pip install -r requirements.txt

What gets installed:
    • streamlit (dashboard framework)
    • pandas, numpy (data processing)
    • yfinance (stock prices)
    • plotly (charts)
    • google-api-client (Google Sheets)
    • And more...

Takes ~2-3 minutes.


STEP 3: CONFIGURE ENVIRONMENT
─────────────────────────────────────────────────────────────────────────────────

Copy the environment template:
    cp .env.example .env

Edit .env and add your email (for SEC EDGAR):
    SEC_EDGAR_USER_AGENT=StockScreenerDashboard (your.email@example.com)

Save the file.


STEP 4: RUN THE DASHBOARD
─────────────────────────────────────────────────────────────────────────────────

Start Streamlit server:
    streamlit run dashboard/app.py

You should see:
    ✓ "You can now view your Streamlit app in your browser"
    ✓ "Local URL: http://localhost:8501"


STEP 5: OPEN IN BROWSER
─────────────────────────────────────────────────────────────────────────────────

Open your web browser and go to:
    http://localhost:8501

You should see the Stock Screener dashboard with 5 pages:
    📊 Dashboard (overview)
    🛠️ Strategy Builder (create strategies)
    🔍 Run Screener (test strategies)
    📋 Fundamentals (company data)
    🔄 Data Refresh (fetch market data)

WHAT TO DO NEXT

OPTION A: Explore with Demo Data

OPTION B: Create Your First Strategy
─────────────────────────────────────────────────────────────────────────────────
1. Go to "Strategy Builder" page
2. Paste this example (220 EMA Breakout):

{
  "name": "220 EMA Breakout",
  "root": {
    "logic": "AND",
    "items": [
      {"metric": "sma150", "operator": ">", "compare_type": "metric", "compare_metric": "ema220"},
      {"metric": "price", "operator": ">", "compare_type": "metric", "compare_metric": "sma50"},
      {"metric": "sma50", "operator": ">", "compare_type": "metric", "compare_metric": "sma150"},

═════════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: No module named 'stockscreener'"
Solution:
    1. Ensure you're in the project root directory
    2. Ensure virtual environment is activated: .venv\Scripts\activate
    3. Try: pip install -e .


Problem: Dashboard won't open (port 8501)
Solution:
    # Kill existing process
    netstat -ano | findstr :8501
    taskkill /PID <PID> /F

    # Try different port
    streamlit run dashboard/app.py --server.port 8502
    # Then go to http://localhost:8502


Problem: "database is locked" error
Solution:
    1. Press Ctrl+C to stop the dashboard
    2. Wait 5 seconds
    3. Restart: streamlit run dashboard/app.py


Problem: No strategies appear in Run Screener
Solution:
    1. Go to Strategy Builder page
    2. Create and save at least one strategy
    3. Refresh your browser (F5)
    4. Go back to Run Screener


Problem: No stocks to screen
Solution:
    Need to load data first:
    1. Go to Data Refresh page
    2. Click "Refresh US Companies Universe"
    3. Click "Refresh Price Data"
    4. Wait for completion
    5. Then strategies will have data to screen
